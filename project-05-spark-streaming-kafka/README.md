# Project 5 — Spark Streaming + Kafka

Continuous Kafka events processed with Spark Structured Streaming, windows, watermarks, and a PostgreSQL sink.

## Technology

Kafka, PySpark, PostgreSQL

## Source
This repository is the companion implementation for *Advanced Data Engineering Projects with Python, SQL & Cloud*. Code follows the manuscript's project examples; local credentials/endpoints are parameterized for public GitHub use.

## Safety
Never commit real credentials, API keys, cloud account IDs, or production data. Use environment variables and synthetic data.
