# ⚠️ Important Security Notice

Never commit sensitive information to GitHub.

Do not commit:

- AWS access keys
- AWS secret keys
- passwords
- database credentials
- API keys
- access tokens
- private certificates
- production configuration

Use environment variables and `.env.example` files instead.

---

# ☁️ Cloud Cost Notice

Some projects use AWS services.

Running AWS resources may result in charges.

Before running cloud-based projects:

1. Review the AWS pricing for the services being used.
2. Use appropriate IAM permissions.
3. Monitor your AWS resources.
4. Delete resources when they are no longer required.
5. Never use production credentials for experimentation.

# 🛠️ Technical Support

If you encounter an issue with the companion code:

1. Check the project's README.
2. Review the troubleshooting section.
3. Check existing GitHub Issues.
4. Open a new issue if the problem has not already been reported.

When reporting an issue, include:

- Project name
- Operating system
- Python version
- Relevant technology/tool version
- Error message
- Steps to reproduce the problem

Never include passwords, API keys, tokens, or other secrets in an issue.
